# 🚀 LearnFlow AI – AI-powered Learning + Developer Productivity Assistant

LearnFlow AI is a smart web application built for students and developers to boost learning and coding productivity using AI.

It provides multiple tools like:

✅ AI Tutor  
✅ Smart Roadmap Generator  
✅ Quiz Generator  
✅ Debug Helper  
✅ Documentation Assistant  

---

## 🌟 Features

### 📘 AI Tutor
Enter any topic and get a simple AI explanation instantly.

### 🗺 Smart Roadmap Generator
Provide your goal and AI creates a day-wise learning roadmap.

### 📝 Quiz Generator
Generate practice quiz questions for any subject/topic.

### 🐞 Debug Helper
Paste coding errors and AI suggests fixes.

### 📄 Docs Assistant
Generate instant documentation for your code.
